# بوابة ركائز للموظفين

موقع مستقل جاهز للرفع إلى مستودع GitHub Pages منفصل، ويستخدم نفس مشروع Firebase الخاص بنظام الإدارة.

## قبل التشغيل

1. فعّل **Anonymous Authentication** من Firebase Authentication > Sign-in method.
2. أضف نطاق GitHub Pages الجديد إلى Authorized domains.
3. ارفع محتويات هذا المجلد إلى جذر المستودع الجديد.
4. تأكد أن قواعد Realtime Database وStorage تسمح للمستخدم المجهول الموثق بالوصول المطلوب فقط. يفضّل وضع قواعد محكمة قبل الاستخدام الفعلي.

يدخل الموظف مباشرة برقم هاتفه الشخصي المرتبط بملفه، من دون رمز واتساب أو رمز دخول إضافي. ويمكنه اختيار العربية أو الإنجليزية من الزر الظاهر أعلى البوابة؛ ويُحفظ اختياره على الجهاز وتتحول الواجهة واتجاهها بالكامل إلى اللغة المختارة. تستخدم البوابة الكاميرا لمسح باركود الفرع وتتحقق من موقع الجهاز قبل تسجيل الدخول أو الخروج.

## أماكن البصمة

بعد تسجيل دخول المدير إلى ركائز، افتح: **الإعدادات ← أماكن البصمة** ثم اضغط **نقل الأماكن والباركودات الأصلية** مرة واحدة. سينقل ذلك باركودات حولي وأبو الحصانية واليرموك وإحداثياتها ونطاقها كما كانت في النظام القديم إلى قاعدة بيانات ركائز.
